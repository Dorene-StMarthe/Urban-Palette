
# Urban-Palette

This is a resturant app, inspired by Caribbean Cuisine. I explored webpacks with this project and tried my hand at recreating a sleek design. 

## Author

- [@Dorene-St.Marthe](https://github.com/Dorene-StMarthe)


## Deployment
Install dependencies:
npm install

Run the Webpack Dev Server:
npx webpack serve

Open the browser at http://localhost:8080.

## Launch App

https://dorene-stmarthe.github.io/Urban-Palette/
